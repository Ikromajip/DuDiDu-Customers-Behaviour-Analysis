# Customers Behaviour Analysis

## Project Overview
This project analyzes household shopping behavior using Dunnhumby’s *The Complete Journey* dataset then, I animated it into DuDiDu Retail for this project. The goal is to identify customer spending patterns and behavioral segments that can inform retail growth strategies.

## Business Problem
How can a retailer increase average customer spending per household by 10% over the next 12 months by identifying the purchasing behavior patterns that differentiate customer value?

## Objectives
- Understand household spending patterns.
- Analyze purchase frequency and average basket value.
- Segment customers based on shopping behavior.
- Identify business opportunities and actionable recommendations.

## Tools
- Spreadsheet -  data dictionary and cleaning
- Python — data preparation and cleaning
- Tableau — exploratory analysis and dashboard visualization

## Analytical Framework
1. **Customer Value** — understand household spending distribution.
2. **Behavior Drivers** — examine purchase frequency and average basket value.
3. **Customer Segmentation** — identify four behavioral segments using median thresholds.
4. **Business Opportunities** — develop targeted strategies for retention, basket growth, frequency improvement, and customer activation.
